# Synto Privacy Policy

**Last updated:** 30 June 2026

This Privacy Policy explains how **Synto** (“Synto”, “the Bot”, “we”, “us”, or “our”) collects, uses, stores, and deletes data when you invite, configure, use, or interact with Synto on Discord.

By using Synto, you agree to this Privacy Policy. If you do not agree, you should stop using Synto and remove it from your Discord server.

## 1. Summary

Synto collects and stores limited Discord-related data needed to provide its features, maintain server-specific settings, operate temporary voice channels, run games, track counting progress, send welcome messages, and record basic usage metrics.

Synto does not sell personal data.

Synto does not intentionally collect payment information, passwords, private Discord account credentials, or direct message content.

## 2. Data Synto may collect

Depending on how Synto is configured and used, Synto may collect and process the following types of data.

### 2.1 Server data

Synto may collect and store:

* Discord server IDs;
* configured channel IDs;
* configured role IDs;
* server-specific configuration settings;
* feature activation settings;
* counting channel settings;
* welcome message settings;
* automatic voice channel settings.

This data is used so Synto can remember how each server has configured the Bot.

### 2.2 User data

Synto may collect and store:

* Discord user IDs;
* command usage linked to a user ID;
* counting interaction data linked to a user ID;
* game interaction data linked to a user ID;
* automatic voice channel action data linked to a user ID;
* welcome message event data linked to a user ID.

This data is used to operate Synto’s features, prevent feature abuse, maintain bot functionality, and understand how the Bot is being used.

### 2.3 Command and usage metrics

Synto may log basic usage metrics, including, but not limited to:

* user ID;
* server ID;
* timestamp;
* action type;
* command name;
* automatic voice channel action type;
* game usage;
* counting actions;
* welcome message events.

These logs are used for debugging, analytics, abuse prevention, reliability, and improving Synto.

### 2.4 Counting data

For the counting feature, Synto may store:

* server ID;
* counting channel ID;
* current count;
* high score;
* latest relevant message ID;
* latest relevant user ID;
* whether double counting is enabled.

This is needed for the counting feature to work correctly.

### 2.5 Welcome message data

For the welcome message feature, Synto may store:

* server ID;
* welcome channel ID;
* welcome message title;
* welcome message description;
* welcome embed colour;
* whether the feature is enabled.

When a member joins a server where welcome messages are enabled, Synto may process the joining member’s Discord ID, account creation timestamp, display avatar, and mention in order to create the welcome message.

### 2.6 Automatic voice channel data

For automatic voice channels, Synto may process or temporarily store:

* server ID;
* configured voice channel creator ID;
* configured category ID;
* configured member role ID;
* configured moderator role IDs;
* temporary voice channel IDs;
* temporary voice channel owner user IDs;
* voice channel names;
* voice channel permission changes;
* voice channel control actions, such as: lock, unlock, hide, show, rename, kick, invite, claim ownership, and set user limit.

Some automatic voice channel data may be stored temporarily in memory while the Bot is running. Server configuration data may be stored persistently so the feature continues working after restarts.

### 2.7 Message content

Synto does not intentionally store general message content.

However, Synto may process message content where required for specific features, such as checking whether a message in a configured counting channel contains the next valid number.

Synto may also store administrator-configured text, such as welcome message titles and descriptions.

### 2.8 Discord data accessible through permissions

Depending on the permissions and intents granted to Synto, the Bot may be technically able to receive certain Discord events or data from servers where it is installed.

Synto aims to process only the data needed to provide its features, maintain reliability, enforce permissions, and support basic operational logging.

## 3. How Synto uses data

Synto uses collected data to:

* provide bot features;
* save server-specific settings;
* operate automatic voice channels;
* manage voice channel control actions;
* run counting features;
* run mini-games;
* send welcome messages;
* respond to commands;
* maintain bot reliability;
* debug errors and technical issues;
* understand feature usage;
* prevent abuse or misuse;
* comply with Discord’s developer requirements;
* respond to support requests.

## 4. Legal basis for processing

Where applicable, Synto processes data on the basis that it is necessary to provide the Bot’s services, operate requested features, maintain security and reliability, and support legitimate interests such as debugging, abuse prevention, and service improvement.

Server administrators are responsible for ensuring they have authority to add and configure Synto in their servers.

## 5. Data sharing

Synto does not sell personal data.

Synto may share or expose data only in limited circumstances:

* with Discord, as necessary for the Bot to function through Discord’s platform and APIs;
* with hosting, database, or infrastructure providers used to operate Synto;
* with server members where a feature intentionally displays information, such as welcome messages, game messages, counting messages, or voice channel changes;
* with support or development personnel where needed to investigate issues or abuse;
* with authorised users within a relevant Discord server through web dashboards or interfaces that display tracked metrics;
* where required by law, legal process, or to protect rights, safety, or security.

## 6. Data retention

Synto keeps data only for as long as reasonably needed for the purposes described in this Privacy Policy.

Typical retention includes:

* server configuration data: kept while Synto remains configured for the server;
* counting data: kept while the counting feature is configured or until reset/deleted;
* welcome message settings: kept while the feature is configured or until reset/deleted;
* automatic voice channel settings: kept while the feature is configured or until reset/deleted;
* usage metrics and logs: kept for operational, debugging, analytics, and abuse-prevention purposes;
* temporary voice channel runtime data: generally kept only while needed for the active temporary voice channel system.

When Synto leaves or is removed from a server, server-specific feature data may be deleted automatically where supported by the Bot. Some logs or backups may remain for a limited period where needed for security, debugging, legal, or operational reasons.

## 7. Data deletion requests

Server owners or authorised administrators may request deletion of server-specific Synto data by contacting support through the official Synto support server:

**Synto Support Server:** https://discord.gg/MdsMmJvaJt

When making a deletion request, please provide:

* the Discord server ID;
* your Discord user ID;
* proof that you are the server owner or authorised administrator;
* what data you want deleted.

Users may also request deletion of data associated with their Discord user ID, where technically possible and legally appropriate.

Some data may be retained if required for security, abuse prevention, legal compliance, dispute resolution, or technical integrity.

## 8. Data security

We take reasonable steps to protect Synto’s stored data, including use of a database, environment-based credentials, and access controls.

However, no system is completely secure. We cannot guarantee absolute security of stored data, hosting systems, Discord APIs, or third-party infrastructure.

If we become aware of a significant data security issue, we will take reasonable steps to investigate and respond.

## 9. Children and minors

Synto is intended for use on Discord and is subject to Discord’s own age requirements.

Synto is not directed at children outside the permitted age requirements of Discord. Server owners and administrators are responsible for ensuring their server’s use of Synto complies with Discord’s rules and applicable laws.
